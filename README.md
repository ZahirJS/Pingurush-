## 🎮 Características

- **Movimiento fluido** con controles WASD o flechas
- **Sistema de Sprint** - Mantén presionado Shift para ir más rápido
- **Enemigos dinámicos** que aparecen aleatoriamente
- **Animaciones suaves** con sprites personalizados
- **Puntuación en tiempo real**

## 🕹️ Controles

- **WASD** o **Flechas**: Movimiento
- **Shift**: Sprint (velocidad extra)
- **Esquiva** a todos los enemigos para sobrevivir

## 🚀 Desarrollado con

- **Godot Engine 4.x**
- **GDScript**
- **Sprites originales**
